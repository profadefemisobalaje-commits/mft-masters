## Reusing the figures

```python
import sys; sys.path.insert(0, "scripts")
from figs_theory import fig04
fig04().save("my-genogram.svg")
```

Colours are defined at the top of `scripts/figstyle.py` (`TEAL`, `ROSE`, `AMBER`, `PLUM`, `BLUE`,
`GREEN`, `SLATE`). Change them once and every figure in the library follows, which is how you adapt the
set to an institution's brand without redrawing anything.
