## What is inside each PDF

1. **Cover** — course code, title, semester, unit value, prerequisite, a count of the practicals, cases and figures in the volume, and a one-line epigraph taken from the course rationale.
2. **Imprint page** — how to cite the volume, the CC BY 4.0 licence, and the statement that all case material is fictional and composite.
3. **The lecture library** — every course in the programme, with the current volume marked in the margin, so a student can see where the book sits.
4. **Contents** — chapters and sub-sections with real page numbers, generated by a second typesetting pass and matched to the bookmarks.
5. **Body** — the full course: fourteen teaching weeks; callout panels for cases, practicals, cautions, debates and reflections; tables whose header row repeats across page breaks; every figure rasterised at 2000 px and embedded.
6. **Back matter** — integration chapter, glossary, self-assessment paper with model answers, further reading.

## How the PDFs are built

```bash
# one-time: rasteriser for the SVG figures
npm install --no-save @resvg/resvg-js
# (or reuse an existing install: export NODE_PATH=/path/to/node_modules)

python3 scripts/build_pdfs.py                  # 28 course PDFs -> pdf/
python3 scripts/build_pdfs.py --complete       # + the merged volume
python3 scripts/build_pdfs.py --only MFT-701   # one book while editing
python3 scripts/build_pdfs.py --programme      # + the four programme documents
```

Requirements: `reportlab`, `pillow`, `pypdf`, and `node` with `@resvg/resvg-js`. The Markdown files remain the single source of truth: rebuild after any text edit and the contents, page numbers and bookmarks follow automatically.

## Typography and production notes

- **Trim:** A4 (210 × 297 mm); 60/56 mm side margins, 70 mm head, 62 mm foot.
- **Type:** DejaVu Serif 10.15/15.1 pt for text, DejaVu Sans for headings and tables; italic faces are synthesised by shearing when a distribution ships none, so the PDFs are identical on any machine.
- **Figures:** SVG sources in `assets/figures/` are rasterised to PNG and embedded, so no viewer has to render SVG.
- **Navigation:** a bookmark for every chapter and sub-section; the merged file nests each course's bookmarks under its own heading.
- **Printing:** duplex, A4, no bleed. Running head at the top of each body page, folio centred in the foot.
